# DraftEngine

DraftEngine is an AI-powered contract drafting assistant for solo attorneys and small law firms. Built as a pure native Windows desktop application using .NET 8 and WPF with MVVM.

## Features
- Contract type selection (starting with Mutual NDA)
- Dynamic intake forms
- Clause library with selection
- AI-powered contract generation and chat-based editing
- DOCX and PDF export
- Local SQLite storage
- Settings management

## Tech Stack
- C# (.NET 8)
- WPF + CommunityToolkit.Mvvm (MVVM)
- Entity Framework Core + SQLite
- OpenAI API (gpt-4o/gpt-4o-mini)
- Open XML SDK + QuestPDF
- Serilog, Microsoft.Extensions.DependencyInjection/Hosting
